# Privacy & Publication Boundaries

This repository is an independently created portfolio reconstruction designed to demonstrate transferable analytics, SQL, data-modeling, measurement, testing, and governance skills without publishing employer intellectual property.

## Included

- synthetic dealer and sales hierarchy data
- generalized sports-product names
- synthetic activation, unit, and revenue values
- independently written SQL
- generalized customer/viewing-segment logic
- independently written tests and CI configuration

## Not included

- employer production data
- proprietary table, view, field, or platform names
- real customer, dealer, employee, vendor, or partner identifiers
- historical service or package codes
- production SQL or source code
- internal reporting layouts, screenshots, paths, credentials, architecture, contractual terms, or operational thresholds

The project demonstrates the analytical pattern only. It should not be interpreted as a reproduction of any employer production implementation.
